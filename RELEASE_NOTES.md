# Agent Folder 0.1.0

Agent Folder helps you keep frequently used folders close at hand and open them quickly in supported editors or File Explorer.

## Highlights

- Search saved folders by name, path, or tags.
- Pin favorites and keep a recent-use history.
- Browse folders or scan configured roots for projects.
- Open projects with VS Code, VS Code Insiders, Cursor, Windsurf, or File Explorer.
- Use the system tray, configurable main-window shortcut, and quick-launch palette.
- Import and export folder records as JSON.

## Privacy

The app stores its folder list and settings locally in `%APPDATA%\agent-folder\data.json`. The installer contains the application only; it does not contain the publisher's folder records, settings, credentials, access tokens, or personal workspace files. The app does not include telemetry or automatic updates.

## Install

Download `Agent Folder_0.1.0_x64-setup.exe` below and run it. Windows 10 or later and Microsoft Edge WebView2 Runtime are required.
